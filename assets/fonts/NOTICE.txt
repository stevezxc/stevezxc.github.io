Web fonts in this directory
===========================

Each subdirectory holds one font as unicode-range woff2 subsets plus the
stylesheet that declares them, produced by scripts/split-fonts.mjs from the
upstream release files. Each font is a modified version distributed under
its own license; the license text and copyright notice are in its directory.
The fonts are separate files combined only by the CSS font-family stack;
no glyphs of one font are merged into another.
